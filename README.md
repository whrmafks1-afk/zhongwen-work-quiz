# 중국어 한입 퀴즈

출근길 5분, 업무 중국어 표현을 가볍게 익히는 퀴즈 사이트입니다.

- 16개 업무 표현 문제 중 매 라운드 10문제 출제
- 한자·병음 + 🔊 발음 듣기 (Web Speech API, zh-CN)
- 정답 시 컨페티·캐릭터 축하, 🔥 연속 정답 콤보
- 완료 화면: 점수·최고 연속, 틀린 문제만 다시 풀기, 새 퀴즈 시작
- 모바일 우선 레이아웃 (한 화면에 문제와 보기 4개)
